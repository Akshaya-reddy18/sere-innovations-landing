# Sere Innovations Landing Page

A modern landing page for Sere Innovations, built with React, TypeScript, Vite, Tailwind CSS v4, and TanStack Router.

## Tech Stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS 4
- TanStack Router
- Framer Motion
- Lucide Icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm (or Bun)

### Install dependencies

```bash
npm install
```

### Run in development

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Scripts

- `npm run dev` - Start local dev server
- `npm run build` - Create production build
- `npm run build:dev` - Build using development mode
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint
- `npm run format` - Run Prettier formatting

## Project Structure

```text
src/
  components/
    site/        # Landing page sections
    ui/          # Reusable UI components
  routes/        # Route definitions
  assets/        # Images and static assets
  styles.css     # Global styles and theme tokens
```
